# 0003 — Arithmetic & operators

Compute and print the five elementary arithmetic operations on two integers
(`a = 17`, `b = 5`). Go's `/` between two `int`s truncates toward zero
(`17 / 5 → 3`); convert to `float64` (`float64(a) / float64(b)`) for
fractional division. `%%` in a `Printf` format string prints a literal `%`.

## Run

    go run .
