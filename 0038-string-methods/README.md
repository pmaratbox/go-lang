# 0038 — String Methods

Split `"a,b,c"` on commas, upper-case each part, and join them with `-`, printing `A-B-C`. The `strings` package holds the helpers: `Split` returns a `[]string`, `ToUpper` upper-cases each element in a loop, and `Join` recombines with the separator. Strings are immutable byte sequences.
