# 0045 — Abstract Classes & Methods

Define an abstract `Shape` with an abstract `area` and a concrete `describe` that uses it, then implement a `Square` of side 3 and print `area: 9`. Go has no classes or abstract methods. An `interface` declares the required `Area`, and a free function `describe` supplies the shared behavior — composition and interfaces replace abstract base classes.
