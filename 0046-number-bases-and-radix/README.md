# 0046 — Number Bases & Radix

Print the integer `255` in hexadecimal, octal, and binary, producing `hex: ff`, `oct: 377`, and `bin: 11111111`. `fmt`'s verbs cover all three bases: `%x` (hex), `%o` (octal), and `%b` (binary). Unlike many languages, Go's `Printf` has a built-in binary verb.
