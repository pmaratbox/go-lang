# 0051 — Ternary & Conditional Expressions

For each of `4` and `7`, choose `even` or `odd` with a single conditional expression and print `4: even` and `7: odd`. Go deliberately has no ternary operator, so an `if` statement assigns the chosen value (starting from a default). The language designers omitted `?:` to keep one obvious way to branch.
