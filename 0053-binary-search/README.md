# 0053 — Binary Search

Binary-search the sorted array `1, 3, 5, 7, 9` for `7` and print the index where it is found: `found 7 at index 3`. Integer `/` already truncates, so `(lo + hi) / 2` is the midpoint. The stdlib offers `sort.SearchInts` and the generic `slices.BinarySearch`.
