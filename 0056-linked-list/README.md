# 0056 — Linked List

Build a singly-linked list holding `1`, `2`, and `3`, then traverse it from head to tail and print `1 -> 2 -> 3`. A `Node` struct holds `value` and a `*Node` pointer whose zero value `nil` marks the tail; the list is built with `&Node{...}` address-of literals.

## Run

    go run .
