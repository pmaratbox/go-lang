# 0090 — Binary Search Tree

Insert `5, 3, 8, 1, 4` into a binary search tree and print an in-order traversal (which yields the values in sorted order): `1 3 4 5 8`. `*Node` pointers form the tree (nil is an empty subtree); in-order traversal appends each value left-to-right via a pointer to the slice.
