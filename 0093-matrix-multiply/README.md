# 0093 — Matrix Multiply

Multiply the 2x2 matrices `[[1, 2], [3, 4]]` and `[[5, 6], [7, 8]]` and print the product, one row per line: `19 22` and `43 50`. Fixed `[2][2]int` arrays hold the matrices; the triple loop fills each `result[i][j]` with the row-by-column dot product.
