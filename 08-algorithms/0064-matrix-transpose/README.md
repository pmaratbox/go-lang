# 0064 — Matrix Transpose

Transpose the 2x3 matrix `[[1, 2, 3], [4, 5, 6]]` (swap rows and columns) and print the resulting 3x2 matrix, one row per line: `1 4`, `2 5`, `3 6`. A new `cols x rows` slice is filled with `transposed[j][i] = matrix[i][j]`; Go has no transpose helper.

## Run

    go run .
