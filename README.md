# go-lang

Incremental lessons learning Go.

## Prerequisites

- Go toolchain

### Install

- macOS (Homebrew): `brew install go`
- Debian / Ubuntu: `sudo apt install golang-go` (often older; for the latest version use the official tarball)
- Other / latest: see [go.dev/dl](https://go.dev/dl/)

### Verify

    go version

## Lessons

- [0001-hello-world](0001-hello-world/) — print "Hello, world!"
- [0002-variables-and-types](0002-variables-and-types/) — declare and print an int, float, string, and bool

## How to run

See each lesson's `README.md` for the exact command.
